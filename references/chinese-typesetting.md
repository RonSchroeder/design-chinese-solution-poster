# Chinese typesetting

## Visible-language rule

- Use Chinese for every visible heading, eyebrow, subtitle, section label, process caption, placeholder, note, and call to action.
- Do not add English translations or decorative English to create a “consulting” appearance.
- Translate generic terms such as “问题起点”“受控路径”“改善方向”“联合推进” instead of displaying English kickers.
- Keep Latin letters only when explicitly required by the source or user: proper names, product names, standards, model names, or unavoidable acronyms. Mark their nearest HTML element with `data-allow-latin`.
- Do not mark a whole section or poster as allowed merely to bypass verification.

## Baseline at 1200 px export width

- Main title: 52–72 px according to length and line count.
- Module title: 28–38 px.
- Card title: 18–24 px.
- Body: 14–19 px; never below 12 px for final screen output.
- Caption: 12–14 px only when genuinely secondary.

## Fit copy without flattening hierarchy

1. Remove duplication and filler.
2. Shorten labels and separate title from explanation.
3. Adjust the design using professional judgment.
4. Reduce font size only within the allowed role range.

Do not compress every module to the same height. Do not use English or letter spacing as decorative texture. Check Chinese punctuation, line breaks, orphaned one-character lines, and accidental mixed-width spacing in the final render.
