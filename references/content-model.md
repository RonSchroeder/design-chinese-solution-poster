# Content model

## Build the content matrix

Capture only supported material:

| Field | Question |
| --- | --- |
| Audience | Who must understand or decide? |
| Dominant question | What single question must the poster answer? |
| Current state | What exists now? |
| Tension | What is difficult, risky, slow, fragmented, or misunderstood? |
| Insight | What reframes the problem? |
| Recommendation | What should change? |
| Evidence | Which examples, facts, mechanisms, or cases support it? |
| Governance | What bounds, reviews, or controls the recommendation? |
| Action | What should the reader do next? |

Do not force empty fields into the poster.

## Write the material signature

- Narrative type: journey, diagnosis, comparison, architecture, evidence, campaign, decision, or hybrid.
- Dominant relationship: sequence, hierarchy, contrast, cause, feedback loop, ecosystem, or grouping.
- Strongest evidence or distinctive content.
- Natural item counts and unequal priorities.
- One content-specific visual device.
- Content that should remain quiet text rather than become a card.

## Audit claims

- Trace every number, certification, result, customer fact, and promise to the source.
- Convert unsupported effects into qualitative directions such as “更清晰”“更易追溯” or “有助于减少重复梳理”.
- Separate observation, diagnosis, recommendation, capability, expected improvement, and governance.
- Remove repeated principles; place each at the point where it changes a decision.
