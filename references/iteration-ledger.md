# Iteration ledger

| Observed problem | Root cause | Reusable correction | Verification |
| --- | --- | --- | --- |
| English appeared in a Chinese poster | English was added as decorative texture rather than required content | Keep visible copy Chinese; allow Latin only when source-required and mark it explicitly | Run strict verification and inspect all headings |
| Pale icon fills disappeared during green removal | The matte threshold treated reflected green or light colors as background | Key on green excess, use a soft transition, despill, and protect neutral colors | Inspect alpha bounds on light and dark backgrounds |
| Cropping removed important scene content | The illustration ratio did not match its final container | Generate or select an asset suitable for the actual slot | Verify no people or semantic objects are unintentionally cropped |
| Unsupported effects sounded fabricated | The source described intent, not measured results | Use qualitative language and avoid invented numbers | Trace every claim to source content |

Reuse a correction only when the root cause matches. Do not turn a past design preference into a universal rule.
